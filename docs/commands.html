Commands

OpenSyntax has regular CLI commands and interactive slash commands. Slash commands are available after starting `opensyntax` without a one-shot prompt.

CLI commands

CommandPurposeExample
opensyntaxStart interactive chat.opensyntax
opensyntax "prompt"Run a one-shot request.opensyntax "fix TypeScript errors"
opensyntax authConnect or update provider credentials.opensyntax auth --provider nvidia
opensyntax providersShow provider connection state.opensyntax providers
opensyntax modelsDiscover models for active provider.opensyntax models openai
opensyntax doctorRun local health checks.opensyntax doctor

Interactive slash commands

CommandPurposeExpected output
/helpShow available commands.Command list.
/clearClear terminal screen.Blank screen with prompt.
/providersList providers and connection state.Provider table.
/modelShow active model.nvidia/meta/llama...
/model gpt-4o-miniSwitch current session model.Model updated message.
/authShow auth state.Connected providers.
/loginConnect or update provider.Setup prompts.
/logoutRemove provider credentials.Confirmation prompt.
/doctorCheck provider, git, and streaming.Health report.
/sessionList saved sessions.Session IDs.
/toolsList agent tools.Tool names.
/planShow task plan.Pending/completed steps.
/diffAsk agent to inspect git diff.Diff summary.
/exitQuit OpenSyntax.Returns to shell.
